## 1. What is the difference between a commit and a push?

Answer: A commit saves your changes on your device while a push uploads those changes to the github so others can see them.

## 2. Why work on a branch instead of directly on `main`?

Answer: Working on a seperate breanch instead of the main keeps your main stable and safe from changes to the others.

## 3. What does a pull request make possible?

Answer: A pull request makes it possible to review, test and have changes before deciding to intergrate it with the main.
